15 Reglas en lenguaje natural
=====================================

1. Si la persona tiene 18 años o más, se considera mayor de edad.
2. Saber si un usario esta activo
3. Saber si hay dinero
4. La persona debe ser mayor de edad Y tener autorización.
5. Puede comprar si tiene suficiente dinero O tiene crédito aprobado.
6. Debe ser mayor de edad Y tener licencia.
7. Saber si alguien tiene el acceso permitido.
8. Es posible retirar dinero.
9. Si la compra es superior a cierto valor Y el cliente es frecuente, recibe descuento.
10. Una persona puede ingresar si tiene invitación O es empleado.
11. Si la gasolina es menor al mínimo permitido, se muestra una advertencia.
12. Si el cliente tiene puntos suficientes Y su cuenta está activa, puede acceder a una promoción.
13. Si el vehículo supera la velocidad máxima O el conductor no tiene autorización, se genera una advertencia.
14. Si la nota es igual o superior a 3.0, el estudiante aprueba.
15. Si el usuario tiene saldo suficiente Y tiene un cupón, puede realizar la compra con beneficio.
